# Crocs Size Finder

אב-טיפוס של כלי שממליץ על מידה ודגם של קרוקס.

**לצפייה:** https://yaelhazam.github.io/crocs-size-finder

## מה הכלי עושה
- מקבל אורך ורוחב של כף הרגל, איך הנעל צריכה לשבת ובשביל מה היא.
- מחזיר מידה (EU ו-US), שלושה דגמים מתאימים והסבר לבחירה, למשל "בין שתי מידות. הדגם מרווח, אז יורדים לקטנה".
- מציג מחיר, מלאי באתר ובדיקה בסניפים. המלאי בסניפים הוא הדגמה בלבד.
- מחזיר את התשובה גם כ-JSON, כמו API שאתר, קופה או מסך בסניף יכולים לצרוך.

## הנתונים
12 דגמים למבוגרים שנאספו מהאתר של WeShoes ב-5.11.2026, יחד עם טבלת המידות של Crocs.
סוג ההתאמה (מרווחת, נינוחה או צמודה) מבוסס על מדריכי מידות בשלושה דגמים. בשאר הדגמים זו הערכה, והיא מסומנת בכלי כ"משוער".

## איך זה בנוי
HTML, CSS ו-JavaScript נקי, בלי ספריות.
ההמלצה מבוססת על כללים שקופים ולא על מודל, כך שאפשר לבדוק אותה בטסטים ולהסביר כל תשובה.

```
index.html   המבנה
style.css    העיצוב
script.js    הקטלוג, כללי המידות והתצוגה
```

## השלבים הבאים
1. משיכת הקטלוג המלא דרך ה-API של מערכת המסחר.
2. איחוד צבעים תחת דגם אחד לפי קוד ה-SKU.
3. חיבור למלאי חי בסניפים.
4. שכבת AI שמתרגמת תיאור חופשי ("רגל רחבה, עומדת כל היום") לפרמטרים של הכלי.

---

A prototype that recommends a Crocs size and model from foot length, width and use. Plain HTML, CSS and JavaScript, rule-based so every answer can be explained and tested.
